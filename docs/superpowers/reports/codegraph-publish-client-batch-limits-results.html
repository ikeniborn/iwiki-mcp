Результаты внедрения: codegraph-publish-client-batch-limits

Клиент code-graph больше не задаёт лимиты батча для удалённой (hosted) публикации — сервер сообщает свои реальные лимиты, клиент их подчиняется (с защитным потолком), отказ по размеру батча теперь содержит точные цифры.
